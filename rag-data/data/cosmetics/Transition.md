# Transition

Transitionsare a type of unlockable cosmetic item introduced inSeason 2. Unlocked transitions can be selected individually, set to Random to select a random image each match, or set it to Default to use an image appropriate to themap.
## Default Transitions
These transitions are used by default. Some of them can also be obtained for permanent use.
