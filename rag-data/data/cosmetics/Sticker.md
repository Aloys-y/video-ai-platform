# Sticker

Stickersare small images that can be placed on certainRegenitems: Health injectors (SyringesandMed Kits),Shield Cells,Shield BatteriesandPhoenix Kits. Only one sticker can be placed on Health Injectors. Shield Cells, Shield Batteries, and Phoenix Kits can have up to 3 stickers. The same sticker can be applied to multiple items.
Two stickers are available by default, and more can be obtained fromEvents, theStoreandBattle Passes.
