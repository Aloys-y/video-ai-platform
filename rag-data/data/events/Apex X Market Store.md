# Apex X Market Store

TheApex X Marketstore event was aminor eventforSeason 11ofApex Legendsthat ran from November 9th, 2021 to November 23rd, 2021. It featured a sale with five bundles containing new skins as well as items from the normal loot table and/or previous events. The skins are a crossover between Apex Legends andMA®KET.
