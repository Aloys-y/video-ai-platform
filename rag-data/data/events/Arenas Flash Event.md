# Arenas Flash Event

Arenas Flash Eventsareminor eventsthat started onSeason 9.
Each event lasts one week and features a set ofArenas-only challenges along with a Prize Track.
## List of Events
The Prize Track Set part of this table identifies which reward and challenge set is used for the specific event.
Event # | Season | Duration | Prize Track Set
Event #1 | Season 9 | May 11 to 18, 2021 | Standard
Event #2 | May 25 to June 01, 2021 | Unique Prize Track
Event #3 | June 08 to 15, 2021 | Standard
Event #4 | Season 10 | August 10 to 16, 2021 | Standard
Event #5 | August 24 to 30, 2021 | Standard
Event #6 | September 7 to 14, 2021 | Unique Prize Track
