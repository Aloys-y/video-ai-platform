# Déjà Loot

Déjà Lootis aLimited Time Modeintroduced inSeason 4'sSystem Override Collection Event.
## Availability
- March 3, 2020 - March 17, 2020
## Details
### Players
- Twenty teams of threeLegendscompete against each other.
### Gameplay
The goal of Déjà Loot is surviving, killing enemy players if necessary.
- Gameplay is the same asPlay Apex.
- The same items spawn in the same locations every match.This never changes.
- The Dropship takes the same route every match.This changes every day.
- The Ringclosures will end up in the same locations every match.This changes every day.
- Care Packagesland in the same locations and contain the same items every match.This changes every day.
### Winning
- The last team that survives wins.
## Maps
- System Override:World's Edge(week 1),Kings Canyon(week 2)
