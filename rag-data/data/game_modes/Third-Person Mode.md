# Third-Person Mode

Third-Person Modeis aLimited Time Modeintroduced inSeason 3'sGrand Soirée Themed Event.
## Availability
- January 18, 2020 - January 20, 2020
## Details
### Players
- Twenty teams of threeLegendscompete against each other.
### Gameplay
The goal of Third-Person Mode is surviving, killing enemy players if necessary.
- Gameplay is the same asBattle Royale.
- Rather than afirst-person point of view, thecamerais positioned behind the Legends so that it gives athird-person point of view.
### Winning
- The last team that survives wins.
