# Game mode

Apex Legendsfeatures a variety ofgame modes, which can go from tweaking the way Battle Royale is played to completely change the gameplay.
There are currently eight permanent modes:Training,Firing Range,Battle Royale TriosandDuos,Ranked Leaguesand the Mixtape (Control,Gun RunandTeam Deathmatch).
During some Events, aLimited Time ModeorTakeovermay be enabled for play. Takeovers directly affect either all or some Battle Royale modes.
