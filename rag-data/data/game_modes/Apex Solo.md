# Apex Solo

Apex Solois aLimited Time Modeintroduced inSeason 2'sIron Crown Collection Event.
## Availability
- August 13, 2019 - August 27, 2019
## Details
### Players
- SixtyLegendscompete against each other.
### Gameplay
The goal of Apex Solo is surviving, killing enemy players if necessary.
- Gameplay is the same asBattle Royale.
### Winning
- The last Legend that survives wins.
