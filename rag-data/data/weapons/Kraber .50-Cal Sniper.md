TheKraber .50-Cal Sniper, orKraber, is a bolt-actionsniper riflethat utilizesMythic Sniper Ammo.
Being aSupply Drop Weapon, it can only be found inCare Packagesand cannot equip foreign ammo. It also comes pre-equipped with 12Ammoand a unique6x-10x Variable Sniperoptic.
