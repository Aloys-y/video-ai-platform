# Pythas Block 0

Pythas Block 0

Gamemode | Arenas,Team Deathmatch
Location | Kómma,Solace
Pythas Block 0is a custom Team Deathmatchmapthat was introduced inSeason 2ofApex Legends Mobile. The map is located on the planetSolace.
## Lore
Pythas Block 0 is a corporate campus located above the city of Kómma. Owned and operated byPythas Inc., it contains many offices for powerful executives.[1]
## Trivia
- Pythas Block 0 is the second map to be located in Kómma, afterParty Crasher.
