# Attachment

The slots for attachments. From left to right:Barrel,Extended Mag,Optic,Stock, andHop-Up.
Attachmentsare items that can improve aweapon's stats. When picked up, they will immediately equip on the appropriate weapon if possible; if not, they can be carried in the inventory.
InBattle Royale, attachments can be found aslootitems anywhere that loot is found.Fully kitted weaponshave the highest quality attachments by default. In othergame modessuch asArenas,Control, orTeam Deathmatch, all weapons are fully kitted weapons, and attachment quality will correspond with the weapon's tier. The exception isoptics, which can be freely swapped out on fully kitted weapons in all game modes.
