## 完整调用链

```text
上传确认 → 固定 analysis_mode → 同事务保存任务与 Outbox → Kafka
→ TaskConsumer → TaskProcessor 按数据库模式分流
→ 原片校验 / 转写 → 文本粗筛 → 候选片段准备
→ 共享有界线程池分析 → 等待片段结果收齐
→ RAG 知识上下文 → 文本汇总 → COMPLETED 落库 → ACK
```

新入口为 `AudioPrefilterPipeline.run(...)`，仍在父消费者线程同步编排。每条消息对应一个视频任务的执行代次，不新增阶段消息、数据库领取队列或调度线程池。

无音轨、无有效语音或零候选会生成覆盖范围说明，明确“未分析画面，不能认定整局无交战”；不调用视频模型或 RAG 编造结论。

## ACK 与异常处理

| 情况 | 处理 |
|---|---|
| 全部片段、汇总成功 | 父任务 COMPLETED 写入成功后 ACK |
| 业务失败 | 普通片段失败先收尾；父任务 FAILED 写入成功后 ACK |
| 已终态、已不存在或旧代次消息 | 核对数据库后 ACK，不重跑模型 |
| 当前代次仍 PROCESSING | 抛出未收敛异常，保留消息，不再次执行付费流水线 |
| 领取/完成/失败条件更新返回 0 | 重新查询；不能证明已终态或旧代次时不 ACK |
| 数据库异常、失败状态也无法可靠保存 | 异常交给 Kafka 容器重投 |
| 取消、总超时、在途片段尚未完全退出 | 停止提交并隔离迟到写入；仅能按已持久化取消/失败处理，不按成功处理 |

容器使用 MANUAL_IMMEDIATE、关闭自动提交；错误处理器每 1 秒重试，不通过默认“达到次数后记录日志并跳过”的方式确认未知结果。反序列化等无法处理的消息也可能阻塞对应分区，需要运维介入，不能把它当作业务成功。

Worker 重启后的 PROCESSING 重投不会自动续跑。已有超时恢复器或消费者确认处理已超过期限后将其标为 FAILED，用户通过原重试接口递增 executionNo；不会因重投重新调用模型。

## 重试复用

新执行仍校验原片 SHA-256 和完整配置。相同时显式绑定历史转写、候选、片段清单的不可变 OSS 引用；每个旧成功片段还核对时间区间和对象键，记录 `reused_execution_no/reused_segment_no` 后复用。

因此，汇总失败后的新代次不重新进行 ASR、粗筛模型和已成功片段的模型调用，但仍有原片摘要、清单及媒体存在性校验的 I/O。失败或未完成片段重新处理，提示词/模型/素材不兼容时拒绝直接复用。

ASR 的 SUBMITTING 等未知状态保持原有保守规则，不自动重复提交。同代次已保存的文本/视频响应仍可直接读取；实际新调用用量与复用来源分开保存。

`tokens_used` 汇总本执行已报告的文本与视频 tokens；无法确认的用量保留 null。ASR 秒数仍在独立记录中，tokens 不是金额账单。

## 总期限

默认 `videoai.worker.task-timeout-minutes=30`，片段排队、限速和处理共享同一截止时间。`ExecutionBudget` 在父调用链绑定，在片段工作线程显式传递并清理：

- 限制 OSS 下载/上传、ASR 与文本 HTTP 请求的单次剩余时间；ASR 轮询不能重新获得完整 30 分钟。
- FFmpeg 的进程和工作区等待取阶段预算与整局剩余时间的较小值；运行期间检查总期限与父任务取消状态。
- 片段池使用 P4 的取消、写入隔离和实际收敛检查；汇总前后、父任务完成前再次核对期限。
- RAG 等已有阻塞调用在边界检查期限，使用各自网络超时；线程中断不保证远端立即停止或停止计费。收尾也需要有限余量，30 分钟不是实时系统的强制终止保证。

启动时校验有效 Kafka 配置：关闭自动提交、每次 poll 1 条、max.poll.interval.ms 必须大于总期限并预留至少 1 分钟。当前默认 40 分钟；实际开发 YAML 也为 1 条 / 40 分钟。关键父终态及进度 SQL 设置 5 秒语句超时。

## 启用方式与剩余工作

API 的 `AUDIO_PREFILTER_ENABLED` 默认 false；需同时配置 `AUDIO_PREFILTER_USER_IDS`（逗号分隔的用户 ID）才对这些用户的新任务启用。关闭开关不会改变已有任务或其重试模式，也不会让在途任务中途改走整片模式。

Worker 需正确设置 `FFMPEG_PATH`、`FFPROBE_PATH`，以及已有的对象存储、DashScope/ASR/文本配置。真实开发环境密钥未写入文档或测试代码。

P6 继续完成前端步骤/片段进度、产物查看、报告事件整理和超长文本分层汇总；当前超出单次汇总预算时明确失败，不截掉片段。P7 再做完整真实录像演示、长片段并发 1/2 对照、账户级限流、费用及质量验收。本轮没有启动正式服务或打开白名单。
