# 语音粗筛与片段分析执行计划

2026-09-07。P0–P6 当前范围已完成；P7 待验收。用户确认只需要片段结果，因此最终模型汇总、分层汇总、跨片段事件合并已移出范围。

## 当前执行链路

```text
API → 任务 + Outbox → Kafka → TaskConsumer → TaskProcessor
→ 下载原片、FFmpeg 音轨 → ASR → 文本粗筛 → 裁剪并上传片段
→ RAG 参考随清单冻结 → 共享有界线程池分析 → Latch 等待
→ 片段结果查询/展示 → 保存任务终态 → ACK
```

片段结果逐个写入，可在处理中或失败后查看；前端查询是独立读链路，不需要等到全部完成。任务状态持久化后才 ACK。

## P4 当前决策

- [x] 每实例固定 4 线程、队列 16；请求启动最小间隔 1 秒，账户总配额另验收。
- [x] 依次提交所有片段，不设单视频滑动窗口。队列满时重试当前片段，不设独立入队超时。
- [x] 父线程短周期 await 并更新进度；检查整局期限、取消、执行代次和线程池关闭。
- [x] 正常/异常退出与启动前取消准确计数；Future 取消不当作远端请求实际结束。
- [x] 普通片段失败不取消其他片段；全部收尾后整局失败，保留成功结果。
- [x] 整局默认 30 分钟、Kafka poll 间隔 40 分钟；修改总期限时同步校验消费参数。
